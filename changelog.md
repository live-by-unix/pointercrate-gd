# Changelog

## [1.2.0] - 2026-10-11

### Added
- In-game demonlist selection menu with native UI
- Single button in main menu that opens selection popup
- Cleaner UI using native Geometry Dash buttons

### Fixed
- Fixed button appearance to use native game sprites
- Removed ugly plaid/purple buttons on Pointercrate and Pemonlist
- All buttons now use consistent native styling

### Changed
- Simplified main menu to single button instead of three separate buttons
- Improved user experience with popup selection menu

## [1.1.0] - 2026-10-11

### Added
- Pemonlist button for platformer demonlist access
- AREDL button for all rated extreme demons list access
- CEF renderer structure for future embedded browser implementation
- Demonlist type enum for managing multiple demonlists

### Changed
- Renamed mod to "Demonlist Browser" to reflect multi-list support
- Updated browser abstraction to support multiple demonlist URLs

## [1.0.0] - 2026-10-09

### Added
- Initial release
- Main menu Demon icon button
- Embedded browser framework (platform-specific implementations)
- Cross-platform support for Windows, macOS, and Android
